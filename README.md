# 🤖 بوت الكويز البرمجي (Quiz Bot)

بوت تليجرام زي Kahoot! بس **مجاني وبتاعك** — للطلاب في مجموعات الجمعة والسبت (الصف الأول الثانوي، مادة البرمجة).

## الملفات
- `bot.py` — نقطة التشغيل الأساسية
- `handlers.py` — استقبال أوامر تليجرام وإدارة الكويز
- `game.py` — حالة الكويز لكل جروب (نقاط، مؤقت، ترتيب)
- `quiz_data.py` — تحميل بنك الأسئلة (مشترك مع Blooket)
- `data/questions.json` — **بنك الأسئلة** (عدّله بسهولة لإضافة أسئلة)
- `scripts/make_blooket_csv.py` — يطلع ملف CSV لاستيراده على Blooket
- `data/blooket_questions.csv` — الملف الجاهز لـ Blooket

## 1) تشغيل البوت على الكمبيوتر

```bash
cd quiz_bot
python -m venv venv
.\venv\Scripts\python -m pip install -r requirements.txt

# 1. خد التوكن من @BotFather على تليجرام
# 2. انسخ الإعدادات:
copy .env.example .env
# 3. افتح .env وحط التوكن:
#    TELEGRAM_BOT_TOKEN=123456:ABCdef...

# 4. شغّل:
.\venv\Scripts\python bot.py
```

## 2) أوامر البوت داخل تليجرام
- `/start` — ترحيب + زرار "ابدأ كويز"
- `/sets` — اختيار موضوع الكويز
- `/myscore` — كل طالب يشوف **درجته وترتيبه** (في الخاص أو جوه الجروب)
- `/help` — طريقة اللعب
- الطلاب يضغطوا على أزرار A/B/C/D، والنقاط على السرعة + الصحة.
- **في نهاية الكويز:** يظهر الترتيب + الفائز 👑، وبعدين البوت **يبعت لكل طالب درجته في الخاص (DM)** تلقائياً (الطالب لازم يكون ضغط /start للبوت مرة في الخاص).

## 3) إضافة أسئلة جديدة
افتح `data/questions.json` و زوّد في `questions` لكل موضوع:
```json
{
  "q": "نص السؤال",
  "options": ["أ", "ب", "ج", "د"],
  "correct": 0,
  "explanation": "تفسير بسيط (اختياري)"
}
```
ملاحظة: `correct` هو رقم الإجابة الصحيحة (يبدأ من 0).

## 4) استخدام Blooket (بديل مجاني ممتع)
1. ادخل blooket.com وسجّل حساب (مجاني).
2. اضغط **Create** ← **Import** ← **Upload CSV**.
3. اختار الملف `data/blooket_questions.csv`.
4. اختار الوضع (ننصح Tower Defense أو Gold Quest للمتعة).
5. ابدأ اللعبة وادّي الكود للطلاب.

## 5) تشغيل البوت 24/7 (اختياري)
عشان البوت يفضل شغال حتى وأنت مقفل الكمبيوتر:
- استضافة مجانية: PythonAnywhere / Render / Railway
- أو شغّله على أي جهاز قديم / Raspberry Pi عندك.

## ملاحظات
- البوت حالياً يخزّن الجلسات في الذاكرة (Single-process) — مناسب للمجموعات.
- لو عايز عدة مجموعات في نفس الوقت، ده شغال لأن كل جروب له جلسة مستقلة.
